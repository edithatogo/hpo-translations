# Authoritative HPO Mapping Source Verification

## Scope and method

This verification was performed on 2026-08-01 using primary project sources only. It records metadata and small public headers; it does not ingest or commit mapping rows. Sources were included when the HPO project named them as HPO-related mappings and the provider exposed a versioned snapshot or immutable Git commit.

The authoritative HPO mapping page at the pinned HPO release names four families: HP–MeSH, HP–UMLS, manually curated HP–MP, and HP–uPheno. The first three hosted Monarch files use mutable `latest` URLs in that page, so the catalog replaces those aliases with date-addressable provider snapshots. The HP–MP collection is pinned to a full repository commit.

## Lineage conclusion

HP–MeSH and HP–UMLS are both described by HPO as derived from MedGen's `MedGenIDMappings.txt`. They therefore share one originating dataset and one independent-evidence group even though they target different identifier systems. HP–uPheno is generated by the uPheno pipeline and forms a separate group. The manually curated HP–MP files are conservatively treated as one collaboration-level group until source-atom provenance is ingested and reviewed.

Accordingly, four mapping families contribute three metadata-level independent-evidence groups. This is a provenance classification, not evidence that any individual mapping or translation is correct.

## License and payload boundary

The Monarch HP–MeSH, HP–UMLS, and HP–uPheno headers declare the SSSOM license as unspecified. The manually curated HP–MP files contain per-file CC0 or CC BY 4.0 declarations, but the repository has no top-level detected license and the project workflow reserves license classification for maintainer review. All mapping payloads therefore remain uncommitted and `payload_commit_allowed` remains false.

The HPO release repository points to a separate HPO website license explanation. Its license is not inferred here. Only public release metadata, URLs, identifiers, sizes, and cryptographic digests are committed.
